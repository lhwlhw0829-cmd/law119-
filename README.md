## 📌 프로젝트 소개

알바 계약서 불법 조항, 깡통전세 위험, 퇴직금 미지급, 병원 과다청구, 소비자 환불 거부...

피해는 매년 수백만 건이지만 법률 상담 비용은 평균 10만 원 이상이고 절차는 복잡합니다.
현재 존재하는 법률 AI는 전부 기업·변호사용입니다.

생활법률 119는 법을 잘 모르는 사람, 소외계층, 전 연령대 누구나 자신의 권리를 찾을 수 있도록 만든 무료 시민 생활법률 AI 플랫폼입니다.

> "법을 아는 것이 권리를 지키는 힘이 되도록"

---

## ✨ 주요 기능

### ⚖️ AI 법률 분석
- 상황을 입력하면 실제 판례·법령 기반으로 위험 여부를 **신호등(🔴🟡🟢)** 으로 즉시 표시
- 관련 법령 클릭 시 **국가법령정보센터** 바로 연결
- 관련 판례 클릭 시 **대법원 법고을** 바로 연결
- 6개 카테고리 지원

| 카테고리 | 주요 기능 |
|---|---|
| 📄 계약서 분석 | 알바·PT·휴대폰 약정 불법 조항 감지 |
| 🏠 부동산·임차인 | 깡통전세 위험도·특약 위험 조항 탐지 |
| 💼 노동권 보호 | 퇴직금·연차수당·미지급 임금 자동 정산 |
| 🏥 의료비 점검 | 병원 과다청구·비급여 오류 감지 |
| 🛍️ 소비자 분쟁 | 환불 거부·배달 사기 대응 |
| 🔧 공과금·하자 | 이상청구·하자보수 청구권 분석 |

### 📝 법적 문서 자동 작성
AI가 실제 제출 가능한 수준의 법적 문서를 작성해드립니다.
- 고소장
- 진정서 (고용노동부)
- 내용증명
- 소비자 신고서
- 하자보수 청구서
- 이의신청서

### 🏛️ 판례·법령 검색
- **API 키 없이도** 국가법령정보센터·대법원 법고을 직접 검색 가능
- AI 연동 시 판례 핵심 내용 요약 제공

### 📞 관련 기관 안내
고용노동부, 법률구조공단, 소비자원, 주거복지센터 등 즉시 연결
